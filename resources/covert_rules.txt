Conditions:
#yaml -> json

type:

DiscountCondition -> COMMON
DiscountCardCondition -> CARD
DiscountCouponCondition -> COUPON

Для наборных (kit) акций технические условия не используются.

Технические условия для основных (default) акций:

Позиция не является частью набора : not cf.isPartOfDisKit()   - необходимо, чтобы основные акции не суммировались с наборными
На товар разрешена скидка : object["tmc"]["price"] > object["tmc"]["minprice"]   - для удобства исключения товаров из участия в акциях. Для этого в АСТУ в справочники товаров, которые нужно исключить, нужно минимальную цену установить равной основной цене.
Позиция не является сертификатом : object["opcode"] != 63   - нельзя давать скидки на подарочный сертификат. 63 - код типа позиции "продажа сертификата".
Технические условия для дополнительных (additional) акций:

На товар разрешена скидка : object["tmc"]["price"] > object["tmc"]["minprice"]   - для удобства исключения товаров из участия в акциях. Для этого в АСТУ в справочники товаров, которые нужно исключить, нужно минимальную цену установить равной основной цене.
Позиция не является сертификатом : object["opcode"] != 63   - нельзя давать скидки на подарочный сертификат. 63 - код типа позиции "продажа сертификата".
